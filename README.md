# Company Website

A modern corporate website built from scratch as a personal learning project focused on web development, software engineering principles, and professional development practices.

---

## 📖 About

This repository documents the complete development of a corporate website, from the initial planning stage to deployment.

The objective is not only to build a functional website, but also to apply professional software engineering practices throughout the entire development process.

---

## 🎯 Learning Objectives

- Learn HTML5, CSS3 and JavaScript.
- Understand how the web works.
- Practice Git and GitHub using a professional workflow.
- Design a scalable project architecture.
- Build a secure Single Page Application (SPA).
- Deploy the project using GitHub Pages.

---

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript (Vanilla)
- Git
- GitHub
- Visual Studio Code
